## 1. Developer Terminal  🐱

**Trigger:** Press the **backtick key** (`` ` ``) anywhere on the page (not in an input field).

| Command | Description |
|---------|-------------|
| `help` | Show all available commands |
| `clear` | Clear the terminal |

| `whoami` | Who are you? |

| `ping` | Ping the server |
| `cat` / `kitten` / `pets` | More cats! |
| `喵` / `喵呜` | Secret Chinese cat |

## 2. Konami Code  🎮

**Trigger:** Press the classic sequence:
```
↑ ↑ ↓ ↓ ← → ← → B A
```

A full-screen particle explosion with emojis fills the screen for 8 seconds.
Click anywhere or wait to dismiss.

## 7. 导出里程碑徽章  🏆

**触发条件：** 累计导出 Excel 达到指定次数

每当你成功导出一份 Excel 文件，系统就会记录一次。达到以下里程碑时，会弹出徽章通知：

| 次数 | 徽章名称 | 图标 |
|------|---------|------|
| 1次  | 初出茅庐 (Data Pioneer) | 🌱 |
| 5次  | 小有成就 (Data Collector) | 📦 |
| 10次 | 数据搬运工 (Data Porter) | 🏋️ |
| 20次 | 数据达人 (Data Pro) | 💫 |
| 50次 | 数据大师 (Data Master) | 🏆 |
| 100次| 数据领主 (Data Overlord) | 👑 |

**记录内容：** 上传记录导出、人员管理导出、操作日志导出、登录日志导出 — 所有 Excel 导出都会被计入。

里程碑数据保存在浏览器本地存储中，换设备不会累计。
